مزامنة سحابية لحالات المرضى ومخطط الأسنان:

عند ربط مشروعك في Supabase، سيتم حفظ كل كيس شيت ومسودة تلقائياً في السحابة لتتمكن من فتحها وتعديلها من أي حاسوب أو هاتف، مع تمكين المشرف السريري من مراجعة الحالات واعتمادها عن بُعد.

الحالة الحالية: غير متصل (يعمل محلياً فقط)
كيف تنشئ قاعدة بيانات سوبابيس مجانية بدقيقة واحدة؟ (خطوات سريعة) انقر للعرض

1. ادخل إلى supabase.com وسجل دخولك بحساب Google أو GitHub مجاناً.

2. اضغط New Project واختر اسماً لمشروعك (مثلاً: e-dental-clinic) وضع كلمة مرور لقاعدة البيانات.

3. من القائمة الجانبية في سوبابيس، افتح Project Settings > API، وانسخ الـ Project URL و anon / public key وضعهما في الخانتين أعلاه.

4. افتح SQL Editor في سوبابيس، واضغط زر [نسخ كود إنشاء الجداول (SQL)] أعلاه، ثم الصقه واضغط Run لتجهيز جداول المرضى والكيس شيت فوراً.
